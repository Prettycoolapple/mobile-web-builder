1. STRIPE SUBSCRIPTION FLOW

   a) /app/api/stripe/checkout/route.ts
      POST endpoint:
      - Authenticate user
      - Create or retrieve Stripe customer (store in profiles.stripe_customer_id)
      - Create Stripe Checkout Session:
        mode: 'subscription'
        line_items: [{ price: STRIPE_PRO_PRICE_ID, quantity: 1 }]
        success_url: /profile?upgraded=true
        cancel_url: /profile
        customer: existing customer ID
        metadata: { user_id: session.user.id }
      - Return { url: checkoutSession.url }

   b) /app/api/stripe/webhook/route.ts
      Handle events:
      - customer.subscription.created / updated:
        → Set profiles.subscription_tier = 'pro'
        → Reset profiles.reports_used_this_month = 0
      - customer.subscription.deleted:
        → Set profiles.subscription_tier = 'free'
      Verify Stripe signature using STRIPE_WEBHOOK_SECRET
      Return 200 immediately, process async

   c) /app/api/stripe/portal/route.ts
      Create a Stripe Customer Portal session for managing billing.
      Return portal URL.

2. USAGE ENFORCEMENT
   Create /lib/usage.ts:
   
   Function: checkUsageLimit(userId: string): Promise<UsageCheck>
   - Fetch profile from Supabase
   - If subscription_tier = 'pro' → always allow
   - If subscription_tier = 'free' AND reports_used_this_month >= 3 
     → return { allowed: false, reason: 'limit_reached' }
   - Otherwise → return { allowed: true }
   
   Function: incrementUsage(userId: string): Promise<void>
   - Increment reports_used_this_month by 1 in Supabase

   Add a cron job (or Supabase scheduled function) to reset 
   reports_used_this_month = 0 on the 1st of each month.

     'You have used your 3 free reports this month.' }
