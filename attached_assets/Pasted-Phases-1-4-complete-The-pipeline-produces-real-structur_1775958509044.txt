Phases 1–4 complete. The pipeline produces real structured data 
with pre-computed scores. Phase 5 renders this into a beautiful, 
trustworthy feasibility report that users will judge the product by.

This phase is UI-heavy. Prioritise clarity, spacing, and mobile 
layout over feature completeness. A clean half-finished report 
beats a cluttered full one.

INSTALL any missing dependencies:
npm install recharts
npm install react-circular-progressbar
(or build score rings from scratch SVG — see Section 2)

2. SCORE RING COMPONENT
/components/report/ScoreRing.tsx
════════════════════════════════

Build with raw SVG — no library needed.

Props: { score: number, label: string, size?: number }

const SIZE = size ?? 88;
const STROKE = 7;
const R = (SIZE - STROKE) / 2;
const CIRC = 2 * Math.PI * R;
const pct = score / 5;
const color = score >= 4 ? '#10B981'    // emerald
            : score >= 2.5 ? '#F59E0B'  // amber  
            : '#EF4444';                 // red

Render:
<svg width={SIZE} height={SIZE} style={{ transform: 'rotate(-90deg)' }}>
  {/* Track */}
  <circle cx={SIZE/2} cy={SIZE/2} r={R}
    fill="none" stroke="#E5E7EB" strokeWidth={STROKE} />
  {/* Fill — animated */}
  <circle cx={SIZE/2} cy={SIZE/2} r={R}
    fill="none" stroke={color} strokeWidth={STROKE}
    strokeDasharray={CIRC}
    strokeDashoffset={CIRC * (1 - pct)}
    strokeLinecap="round"
    style={{ transition: 'stroke-dashoffset 1s ease-in-out' }}
  />
  {/* Score text — counter-rotate so it reads upright */}
  <text x={SIZE/2} y={SIZE/2} 
    textAnchor="middle" dominantBaseline="central"
    style={{ transform: `rotate(90deg) translate(0, -${SIZE/2}px) 
             translate(${SIZE/2}px, 0)`, 
             fontSize: 20, fontWeight: 600, fill: color }}
  >
    {score.toFixed(1)}
  </text>
</svg>

SIMPLER approach for the text (avoids SVG transform complexity):
Use position:relative wrapper div, absolute-position the text 
over the SVG using a <div> overlay, not SVG <text>.

<div style={{ position: 'relative', width: SIZE, height: SIZE }}>
  <svg ...>rings only, no text</svg>
  <div style={{
    position: 'absolute', inset: 0,
    display: 'flex', flexDirection: 'column',
    alignItems: 'center', justifyContent: 'center'
  }}>
    <span style={{ fontSize: 20, fontWeight: 700, color }}>
      {score.toFixed(1)}
    </span>
    <span style={{ fontSize: 11, color: '#6B7280', marginTop: 2 }}>
      {label}
    </span>
  </div>
</div>

Animate on mount using useEffect + setTimeout to trigger 
the CSS transition after initial render.

8. CONTOUR CARD
/components/report/ContourCard.tsx
════════════════════════════════

Props: { contour: string, costs: CostBreakdown }

Show classification badge + SVG slope illustration + cost.

SVG slope illustration (simple triangle):
const angles = { flat: 3, gentle: 10, moderate: 20, steep: 32 };
const deg = angles[contour] ?? 5;
const rad = (deg * Math.PI) / 180;
const baseW = 160;
const h = Math.tan(rad) * baseW;

<svg width={baseW + 20} height={Math.max(h + 20, 40)} 
     viewBox={`0 0 ${baseW + 20} ${Math.max(h + 20, 40)}`}>
  <polygon 
    points={`10,${h + 10} ${baseW + 10},${h + 10} ${baseW + 10},10`}
    fill="#E5E7EB" stroke="#9CA3AF" strokeWidth="1.5"
  />
  <text x="15" y={h + 8} fontSize="11" fill="#6B7280">
    {deg}° slope
  </text>
</svg>

Below the SVG:
Classification: "{Flat|Gentle|Moderate|Steep} terrain"
Retaining cost: "Estimated retaining wall cost: 
                 $${formatNZD(costs.retaining_low)}–
                 $${formatNZD(costs.retaining_high)}"
